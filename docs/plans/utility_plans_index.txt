Recommended Reading Order
1. Read the master harmony plan first.
2. Read the module inventory second.
3. Read the platform overview third.
4. Read the web conversion master plan fourth.
5. Read the full implementation checklist fifth.
6. Read the accounting, finance/map/complaints, and mobile sync files after that.
7. Use the BAPA-specific files only when working on BAPA behavior, BAPA mode logic, or BAPA parity testing.

How The Files Fit Together
- Master harmony plan
  - defines the shared terms and structure
- Module inventory
  - defines the desktop-to-web module map
- Platform overview
  - defines the shared desktop/web/mobile structure
- Web conversion master plan
  - defines the architecture and conversion path
- Full implementation checklist
  - defines the implementation scope and order
- Accounting plan
  - defines export/posting integration
- Finance/map/complaints addendum
  - defines analytics, map, and complaint workflows
- Mobile sync plan
  - defines offline-first mobile synchronization
- Agents and skills matrix
  - maps task types to the best workflow roles
- Task selector
  - gives the shortest routing path for each task type
- Starter bundle
  - tells you when to start and what must be ready first
- Phase 1 prompt
  - exact prompt for the first implementation pass
- Phase 1 agent command
  - copy/paste version for quick task launch
- Prompt pack
  - defines reusable prompts for agents and skills
- BAPA files
  - specialize the shared platform for the BAPA account family

Development Rule
- Keep all future work aligned to the master harmony plan so new modules, reports, and integrations stay consistent.
