UTILITY PLATFORM OVERVIEW

Purpose
- Provide a one-page reference for the full utility platform across desktop, web, and Android mobile.
- Tie the module inventory, web conversion, accounting, finance/map/complaints, and mobile sync plans into one shared picture.

Platforms

1. Desktop Utility
- Source of truth for current business behavior.
- Includes billing, collections, operations, reporting, configuration, and transfers.
- Supports BAPA, regular consumer, net metering, and special account workflows.

2. Web Platform
- Central browser-based system.
- Handles billing, collections, adjustments, reports, audit, reconciliation, and accounting export.
- Uses preview and rollback for all write actions.

3. Android Mobile App
- Offline-first field client.
- Handles readings, collections, disconnection, reconnection, complaints, and reference-data sync.
- Uploads idempotently to the web platform.

Shared Principles
- One billing engine.
- One shared contract model.
- One audit and reconciliation model.
- One duplicate-prevention model.
- One approval and rollback model.
- One sync strategy across all platforms.

Module Relationship Summary
- Desktop modules define the current behavior.
- Web modules recreate and extend the behavior in browser form.
- Mobile modules handle offline field actions and sync back to the shared core.
- Accounting integration consumes approved results from the shared core.

- Do not let one platform drift away from the others.
- If a field, rule, or workflow changes in one place, update the shared contract and audit/reconciliation plan.
